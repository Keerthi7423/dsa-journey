## Key Takeaways
1. Conditional statements control program flow.
2. else provides an alternative branch.
3. else if allows multiple conditions to be checked in order.
4. Nested conditions represent dependent decisions.
5. switch compares its expression with case values using strict matching.
6. break prevents unintended switch fall-through.
7. default handles unmatched cases.
8. Ternary expressions are useful for simple two-way decisions.
