## Key Takeaways
1. Arrays store ordered collections of values.
2. Array indexes start at zero.
3. The length property gives the array's length.
4. const prevents reassignment but does not freeze an array.
5. push and pop operate at the end of an array.
6. shift and unshift operate at the beginning.
7. slice returns a portion without modifying the original.
8. splice modifies the original array.
9. Loops can traverse arrays and process every element.
