## Key Takeaways
1. Functions allow code to be reused.
2. Parameters are defined in the function signature.
3. Arguments are passed during a function call.
4. return sends a value back to the caller.
5. console.log displays a value; it is not a substitute for return.
6. Function expressions can be assigned to variables.
7. Arrow functions provide concise syntax.
8. Default parameters provide fallback values.
9. Local variables are limited by their scope.
10. Pure functions simplify testing and reasoning.
