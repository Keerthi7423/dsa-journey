## Key Concepts
1. JavaScript is dynamically typed.
2. typeof returns a string describing a value's type.
3. Arrays are objects; Array.isArray() identifies arrays.
4. Strings are immutable.
5. Number(), String(), and Boolean() perform explicit conversions.
6. Implicit coercion can happen during operations.
7. === compares without type coercion.
