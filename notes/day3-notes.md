## Key Takeaways
1. Arithmetic operators perform calculations.
2. Comparison operators produce Boolean results.
3. Prefer strict equality (===) over loose equality (==).
4. && and || use short-circuit evaluation.
5. Empty arrays and empty objects are truthy.
6. Boolean(value) explicitly converts a value to Boolean.
7. The ternary operator is useful for simple conditional expressions.
8. The modulo operator (%) is useful for divisibility problems.
